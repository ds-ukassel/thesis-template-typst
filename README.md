# Distributed Systems Thesis Template 
Thesis template of the Distributed Systems Group at the University of Kassel.


## 📎️ Typst
This template uses typst which can easily be [installed](https://github.com/typst/typst#installation) on all common operating systems or be used in the [browser](https://typst.app/play/).


## ✅️ Checklist

- [ ] Adjusted page numbering for roman numbers starting after main content
- [ ] Adjusted title page information
